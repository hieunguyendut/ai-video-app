Privacy Policy

Last updated: November 13, 2026

AI_Video is a personal tool operated and used only by its owner.

What data the app accesses

With the owner's consent, the app uses Google OAuth with the https://www.googleapis.com/auth/drive.file scope. This allows it to create folders and upload video and image files that it generates, and to access only those files. It cannot see or read any other file in the Google Drive account.

How data is used

  • Generated videos and thumbnails are uploaded to the owner's own Google Drive so the owner can publish them later.
  • The OAuth token is stored only on the owner's computer or server and is never shared with anyone.
  • No personal data of other people is collected, sold, shared or used for advertising.

Google API Services User Data Policy

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
